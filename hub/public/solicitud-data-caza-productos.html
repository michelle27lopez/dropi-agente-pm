1. Especificación del Dataset (Estructura de Columnas)

Necesitamos que la extracción retorne un registro por cada solicitud publicada en Caza Productos, con los siguientes campos:

Campo Columna Sugerida Descripción de Negocio Ejemplo / Valores
ID Solicitud solicitud_id Identificador único de la publicación de Caza Productos creada por el dropshipper. CAZ-0041 / UUID
ID Dropshipper dropshipper_id ID del dropshipper (dropi) que publicó la solicitud. 83421
País country País de operación del dropshipper. CO, MX, EC
Categoría categoria Categoría del producto buscado tal como está registrada en el módulo. Bisutería, Calzado, Maquillaje
Descripción del producto descripcion_producto Texto libre que escribió el dropshipper describiendo el producto que necesita. Aretes dorados medianos tipo argolla
Precio deseado precio_deseado Precio máximo que el dropshipper está dispuesto a pagar al proveedor. 18000 (COP)
Estado estado Estado actual de la publicación en la plataforma. ACTIVE EXPIRED CLOSED
Fecha publicación fecha_publicacion Fecha y hora en que el dropshipper publicó la solicitud. 2026-06-15 10:30:00
Fecha vencimiento fecha_vencimiento Fecha en que expira la solicitud y deja de recibir ofertas. 2026-06-30 23:59:59
# Ofertas recibidas num_ofertas Conteo de ofertas enviadas por proveedores a esta solicitud. 0 = nadie ha respondido. 0, 1, 3
# Negociaciones iniciadas num_negociaciones Conteo de negociaciones formales abiertas entre el dropshipper y algún proveedor a partir de esta solicitud. 0, 1, 2

2. Entrega y Accesibilidad

  • Opción preferida: Exportación como archivo CSV o conexión directa a Power BI (vista o tabla en la BD réplica accesible desde el conector).
  • Opción alternativa: Exportación manual puntual como CSV o Excel cuando se solicite.
  • Frecuencia: Semanal (lunes) para alimentar el seguimiento comercial de la semana.
  • Ventana de datos: Últimos 60 días desde la fecha de extracción.

3. Query SQL Lógico de Referencia

Query orientativo para guiar la extracción. Los nombres reales de tablas y columnas en Chronos pueden variar — Miguel los ajusta según el esquema interno:

SELECT cp.id AS solicitud_id, cp.dropshipper_id AS dropshipper_id, cp.country AS country, cp.category AS categoria, cp.description AS descripcion_producto, cp.desired_price AS precio_deseado, cp.status AS estado, cp.created_at AS fecha_publicacion, cp.expires_at AS fecha_vencimiento, COUNT(DISTINCT o.id) AS num_ofertas, COUNT(DISTINCT n.id) AS num_negociaciones FROM dropi_prod.hunt_requests cp LEFT JOIN dropi_prod.hunt_offers o ON o.request_id = cp.id LEFT JOIN dropi_prod.hunt_negotiations n ON n.request_id = cp.id WHERE cp.created_at >= NOW() - INTERVAL '60 days' GROUP BY cp.id, cp.dropshipper_id, cp.country, cp.category, cp.description, cp.desired_price, cp.status, cp.created_at, cp.expires_at ORDER BY cp.status ASC, cp.created_at DESC;
