# Control de entrega (avance vs. objetivo)

## Objetivo
Medir cercanía o desviación frente al objetivo, usando **solo contexto oficial** (specs + ESTADO) y seguimiento reciente.

## Instrucciones
1. Lee el contexto oficial vigente: `ESTADO.md`, `DASHBOARD.md`, `proyectos/<x>/spec.md`, `planning/todos.md`, `planning/sprints.md`, `planning/semana.md`.
2. Reúne seguimiento reciente: `reuniones/`, `planning/daily/`.
3. Compara la ejecución real contra:
   - North Star de logística (Movilización ⬆️, % de entrega ⬆️; Time to Value) — ver `CLAUDE.md` y `metodologia/product-logistics.md`
   - OKRs/KRs, hitos, decisiones, capacidades/features priorizadas, compromisos
4. Si es un proyecto E2E, **audita completitud y calidad** de las secciones contra `metodologia/handoff-ti.md` y el Definition of Ready/Done de `metodologia/spec-driven.md` antes de avalar el paso a desarrollo.
5. Entrega: **avances · desvíos · riesgos · bloqueos · decisiones recomendadas**, agrupado por proyecto/frente.

## Restricciones
- No basar el análisis en borradores no aprobados.
- No inventar estado si faltan datos → marcar el gap y preguntar.
- Español, directo. Agrupar y resumir cuando haya varios tableros.
