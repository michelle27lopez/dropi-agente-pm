# Crear brief de lanzamiento (para comunicaciones)

## Objetivo
Generar el brief de lanzamiento listo para entregar al equipo de comunicaciones/marketing. Lenguaje claro, no técnico.

## Instrucciones
1. Lee la **estructura oficial del brief** en `agente-delivery/canon/dropi_methodology.md` §Brief de Lanzamiento (única fuente de las secciones).
2. Lee el contexto en `proyectos/<x>/spec.md` o la épica/historia si existe.
3. Si falta contexto, **pregunta**: nombre oficial, a quién va dirigido (tipo de usuario), beneficio principal, fecha/ventana de lanzamiento, responsable de producto.
4. Genera EN ESTE ORDEN:
   - **1. Título** (nombre oficial)
   - **2. Descripción general** — ¿qué es? (2-3 líneas), ¿para quién?
   - **3. Beneficios clave** — principal + secundarios (máx. 5 viñetas)
   - **4. Objetivo del lanzamiento** — meta de campaña, fechas, estrategia de producto (qué comunicar, énfasis, tono)
   - **5. Mensajes y ángulos** — mensaje clave (1 frase memorable) + puntos de apoyo
   - **6. Recursos** — tabla: video, Tango, Figma/prototipo, docs (enlace o "por crear")
   - **7. Contacto principal** — responsable de producto + fecha límite de solicitudes
5. Presenta como borrador.

## Restricciones
- Lenguaje no técnico (lo lee comunicaciones, no dev).
- No inventar fechas/nombres/enlaces → `[por definir]`. Mensaje clave = 1 sola frase.
- Español.
