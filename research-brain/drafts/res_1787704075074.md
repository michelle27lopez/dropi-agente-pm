## 📚 Evidencia por Competidor

### Dropi
- **Integraciones:** Integraciones nativas con plataformas CMS como Shopify (vía Dropify), WooCommerce y Tiendanube., Soporte para Chat Center para gestión de ventas vía WhatsApp, además de opción de carga manual de órdenes.
- **Autorización y Sync:** La integración se realiza mediante el uso de tokens de API proporcionados por la plataforma Dropi, los cuales deben ser configurados en el plugin o aplicación de la tienda (ej. Dropify para Shopify o configuración directa en WooCommerce)., Los usuarios pueden gestionar y administrar sus tokens desde la sección específica de 'ver tokens' dentro de su cuenta en la plataforma.
- **Experiencia del Seller:** Proceso paso a paso para importar productos, seleccionar precios y configurar la sincronización de inventario., Opción de administrar productos sincronizados desde una sección centralizada en el panel de Dropi.
- **Logística y COD:** Sincronización automatizada de pedidos, incluyendo validación de órdenes para reducir errores., Soporte para métodos de pago contra entrega (COD) y automatización de procesos logísticos (guías y seguimiento).

### Rocketfy
- **Integraciones:** Rocketfy opera como un ecosistema donde los usuarios crean tiendas propias dentro de su plataforma (Rocketfy Shops). Ofrece herramientas de sincronización para la gestión de inventario y pedidos.
- **Autorización y Sync:** Rocketfy gestiona la sincronización a través de una plataforma centralizada que integra catálogos, productos y tiendas. La plataforma utiliza un sistema de gestión de sesiones de usuario e inicio de sesión. No hay información pública detallada sobre la gestión técnica de tokens OAuth o manejo de errores de API específicos.
- **Experiencia del Seller:** Los vendedores tienen acceso a un portal centralizado para gestionar ventas, pedidos, inventario y retiros de dinero. Se enfoca en la facilidad de uso ("crea tu tienda en 3 minutos").
- **Logística y COD:** Rocketfy actúa como intermediario logístico integrando diversas empresas transportadoras. Gestiona la logística, incluyendo pagos contra entrega (COD) y el procesamiento de pagos.

### AutoDS
- **Integraciones:** AutoDS centraliza la gestión de múltiples canales (Shopify, eBay, Etsy, WooCommerce, Wix, Facebook Marketplace) en un único dashboard., Para plataformas como Shopify, la integración implica instalar la app de AutoDS y aprobar permisos; para WooCommerce, requiere activar y configurar la API REST del sitio., Permite cambiar entre tiendas instantáneamente sin necesidad de cerrar sesión, aplicando reglas de automatización globales.
- **Autorización y Sync:** La integración se basa en tokens de tienda (Store Tokens) que actúan como credenciales de seguridad entre AutoDS y el canal de venta (ej. Shopify, eBay, WooCommerce)., Si el token expira o la conexión se vuelve inestable, se debe renovar manualmente en 'Store Settings' o en la sección de la tienda, seguido de una resincronización ('Resync Store') para restablecer la comunicación., La mayoría de las incidencias de sincronización (productos que no aparecen o datos erróneos) se resuelven renovando el token y ejecutando una resincronización manual para forzar la actualización de los datos entre ambas plataformas.
- **Experiencia del Seller:** El dashboard centralizado reduce la carga operativa al evitar el cambio constante de pestañas o cuentas., La sincronización bidireccional (especialmente en Shopify) permite que cambios hechos en el canal de venta (ej. títulos, descripciones, etiquetas) se reflejen automáticamente en AutoDS en segundos, manteniendo el catálogo alineado.
- **Logística y COD:** Automatiza la gestión de pedidos mediante la sincronización de datos desde la tienda hacia AutoDS para su procesamiento y envío a proveedores., Soporta el auto-pedido (auto-ordering) desde proveedores, enviando los detalles y actualizando automáticamente el estado del pedido y la información de rastreo en el canal de venta., El monitoreo de stock y precios asegura que, si un producto se agota o cambia su costo, AutoDS pueda actualizar automáticamente el listado (pausar o ajustar cantidad a cero) para prevenir ventas sin stock.
